# Где региональные отделения ФСП публикуют мероприятия

Разведка: сентябрь 2026. Справочник ссылок — [data/regional-sources.json](../data/regional-sources.json).

## Как искали

- На fsp-russia.ru (страницы регионов, «Анонсы», старый раздел регионов) ссылок на ресурсы отделений нет.
- Перебор типовых имён для каждого из 89 отделений: `fsp_<slug>`, `fsp<slug>`, `fsp.<slug>`, `fsp<код>`, аббревиатуры (`fsp_rt`, `fspnsk`, `fspko43` …). Проверялись `vk.ru/<имя>` (код ответа), `t.me/s/<имя>` (заголовок канала), `fsp-<slug>.ru`.
- Архив Telegram-канала ФСП (~400 последних постов): упоминания региональных каналов (так нашлись `fspko43`, `fsp_RT`, `uralsp`, `orenfsp`, `fsppk`).
- Веб-поиск по сайтам минспортов и календарным планам.

Ограничения: VK без токена не отдаёт название группы, поэтому VK-имена — **кандидаты** (страница существует, но это может быть чужой паблик или профиль). Адаптер VK проверяет название группы через `groups.getById` и отбрасывает чужие. Каналы Telegram проверены по заголовку.

## Рекомендация

1. **Подключать Telegram** — один адаптер на все каналы. Отбор постов по ключевым словам, извлечение названия и дат правилами. Отбрасывать репосты всероссийских мероприятий: они уже есть в ЕКП и календаре ФСП.
2. **Подключать VK** тем же конвейером, если задан `VK_SERVICE_TOKEN`. Группы-кандидаты проверяются по названию.
3. **Сайты не подключать.** Полезного календаря нет ни на одном.
4. **Региональные календарные планы не подключать сейчас.** 85 разных сайтов и форматов (XLSX, PDF, сканы), вид спорта встречается редко (1 строка в Магадане, 0 в СПб). Имеет смысл точечно для 3–5 регионов после ручной проверки.
